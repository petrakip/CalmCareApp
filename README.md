## Description

This repository contains an Android mobile application, developed using Java. 
The project strictly adhered to a three-cycle Spiral Development Model, focusing on the design, implementation, and rigorous evaluation of a specialized user interface
tailored to a specific user group's needs. A key feature of the application is the integration of voice functionality (Speech Recognition/Natural Language Processing) 
to enhance usability and interaction. The repository includes the final fully functional prototype, its source code, and comprehensive documentation. Done as part of a university assignment.
